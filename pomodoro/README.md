# 🍅 Томатный таймер — Помодоро

Небольшое яркое приложение для детей 1–4 классов и итогового урока 19 «Дневник супергероя».

## Возможности
- Настраиваемая длительность работы: **1–120 минут**, отдыха: **1–60 минут**.
- Готовые настройки: **10/2**, **15/5**, **25/5**, **30/10** минут.
- Большой круговой циферблат с помидором, запуск и пауза нажатием на него.
- Сброс, переключение работы и отдыха, звуковой сигнал по желанию.
- После окончания работы отдых начинается автоматически; после отдыха следующий рабочий интервал подготовлен, но не начинается без нажатия.
- Статистика законченных рабочих интервалов и времени работы.
- Таймер использует системное время, поэтому учитывает переключение вкладок и возвращение к странице.
- Сохранение настроек и статистики **только в браузере** через localStorage.
- Адаптация к телефонам, ноутбукам и проекторам; без внешних библиотек, без регистрации, не собирает данные учеников.

## Для урока 19
Выберите **10 / 2**. Дети 10 минут работают над очередной страницей на Holst и 2 минуты отдыхают. Во время паузы можно по желанию выбрать декоративные стикеры для дневника, но это не обязательное условие. Кристаллы за выполнение заданий остаются на Holst; таймер их не выдаёт.

## Использование
Откройте `index.html` в браузере либо опубликуйте сайт через GitHub Pages.

Предполагаемый адрес при размещении из ветки `main` и корня репозитория:

https://maretdangaeva.github.io/emo-vybor/pomodoro/

Если ссылка не открывается, проверьте в GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)** и дождитесь публикации. Папка `pomodoro` уже размещена в существующем репозитории `emo-vybor`; исходная игра не изменена.

## Управление
- Большой помидор — запуск/пауза.
- «Работа» и «Отдых» снизу — перейти к выбранной фазе.
- Кнопки «Сбросить» и «Следующий этап».
- Минуты можно менять в числовых полях, когда отсчёт не запущен.
- Пробел запускает/останавливает таймер, Esc закрывает информационное окно.

Один файл `index.html`: HTML, CSS и JavaScript внутри, никаких серверов и API.
