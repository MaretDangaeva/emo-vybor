# Эмо-выбор — интерактивная новелла для урока 18

Образовательная игра для 1–4 классов: «Эмоциональный интеллект и коммуникация».

## Что внутри

- Три главы: «Плакат», «Игра», «Выступление».
- Пульт эмоций, выбор факта, возможных чувств и реплик, последствия выбора.
- Итоговый маршрут; дополнительный конструктор четвёртой главы для «Премиум».
- Всё работает в браузере, без регистрации и доступа к серверу.
- Файл `index.html` полностью автономный, без внешних изображений и библиотек.
