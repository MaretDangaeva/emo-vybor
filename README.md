# Эмо-выбор — интерактивная новелла для урока 18

Образовательная игра для 1–4 классов: «Эмоциональный интеллект и коммуникация».

## Что внутри

- Три главы: «Плакат», «Игра», «Выступление».
- Пульт эмоций, выбор факта, возможных чувств и реплик, последствия выбора.
- Итоговый маршрут; дополнительный конструктор четвёртой главы для «Премиум».
- Всё работает в браузере, без регистрации и доступа к серверу.
- Файл `index.html` полностью автономный, без внешних изображений и библиотек.

## Публикация на GitHub Pages

1. Войти в GitHub и создать публичный репозиторий `emo-vybor`.
2. Нажать **Add file → Upload files** и загрузить из этого архива `index.html`, `.nojekyll` и `README.md` в корень репозитория. Подтвердить **Commit changes**.
3. Перейти в **Settings → Pages → Build and deployment**.
4. Установить **Source: Deploy from a branch**, **Branch: main**, папка **/(root)** и нажать **Save**.
5. Подождать развёртывания и открыть URL сайта, показанный в **Settings → Pages**. При названии репозитория `emo-vybor` ожидаемый адрес: `https://maretdangaeva.github.io/emo-vybor/` — он заработает только после публикации.

### Обновление игры

В репозитории заменить `index.html` новым вариантом файла и подтвердить изменения; GitHub Pages опубликует обновлённую версию.

## Примечание

Игра вдохновлена общим педагогическим приёмом «пульта эмоций», но использует самостоятельные ситуации и персонажей. Это неофициальный учебный материал, не связанный с правообладателями «Головоломки».
